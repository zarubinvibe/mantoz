# 用对话安装 Mantoz

这不是一页命令，而是一次对话。在你的智能体 CLI 里打开这个项目，说 `/mantoz-setup`。之后由我来讲：每一步在做之前先说清楚，一次只问一个问题，并且给出我的建议，让你用一个词就能同意。没有你的同意，磁盘上不会有任何改变。

## 第 1 步：先看看你机器上已经有什么

**我在做什么：** 运行 `python3 --version`、`uv --version`、`docker --version` 和 `git --version`，然后把有什么、缺什么念出来。这一步不安装任何东西。

**为什么：** 一半失败的安装都始于没人提前告诉这个人机器上缺什么。他后面撞上一条看不懂的报错，就得出结论说产品坏了。

**磁盘上会改变什么：** 什么都不变。这一步只读，不写。

**你会得到：** 一份诚实的清单：这些有，这些没有，缺了它 Mantoz 的哪一部分跑不起来。

**岔路：** 缺 `uv`。它负责搭环境、取来智能体执行所依赖的 Harbor，并自带 Python 3.12，不动你系统里的那个。没有它，你只剩下对目录树的离线检查。装，还是先不装？
➡️ 我建议装上：没有 `uv`，人物生成和运行都起不来。

## 第 2 步：把项目放到磁盘上

**我在做什么：** 问你放在哪里，然后取代码：`git clone` 到你指定的文件夹，或者在没有 git 时用解压好的压缩包。

**为什么：** 之后所有命令都从那个文件夹里跑，你得知道明天回到哪儿。它需要自己的文件夹：Mantoz 会往里面写运行报告，之后还有统计数据，那是好几个 GB。

**磁盘上会改变什么：** 多出一个新文件夹，默认是 `~/mantoz`，大约二十兆。文件夹以外的东西不会被碰。

**你会得到：** 一份可用的副本，以及我念出来的那个路径。

**岔路：** git 还是压缩包。克隆之后用一条 `/mantoz-update` 就能更新；压缩包则要重新下载，并手动搬过去自己的文件。
➡️ 装了 git 的话我建议克隆：以后更新只要一行。

## 第 3 步：装好运行环境

**我在做什么：** 运行 `bash install.sh`。它检查 Python，用 `uv` 搭环境，装 Harbor，最后跑一遍对目录树的离线检查，共二十一项。

**为什么：** Harbor 是别人的 Apache-2.0 项目，智能体执行靠它。我们把它当作署名的依赖，而不是复制进仓库，所以必须从网络上取。

**磁盘上会改变什么：** 项目文件夹里会出现一个 `.venv`，含 Python 3.12 和依赖，几百兆。安装不会伸到这个文件夹之外。

**你会得到：** 一行 `all 21 checks passed`。没有网络时，安装脚本会直说，并给出之后补装依赖的命令，而目录树的检查照样全部跑完。

## 第 4 步：把这些人生成出来

**我在做什么：** 问你要多少人、用哪个随机种子，然后按四十个特征的结构把他们生成出来，背后是一张依赖图。

**为什么：** 种子让运行可复现。没有它，第二次运行给出的是另一批人，任何关于结果的讨论都没有意义。人数会直接乘进运行时间。

**磁盘上会改变什么：** `runs/` 下多出一个 JSON 文件，通常不到一兆。

**你会得到：** 一个可以打开来读的人物文件：年龄、收入、城市、习惯、价值观。我会完整展示其中一个人，再用同一个种子把命令重跑一遍，让你亲眼看到同一批人回来。

**岔路：** 五百人还是五十人。五百人能让群体差别看得出来；五十人跑得更快，够看清机制。
➡️ 第一次我建议两百人、种子 7：群体已经看得见，又不用等太久。

## 第 5 步：跑你的任务，不是我的

**我在做什么：** 问你最想先验证什么，据此从四个环境里挑一个，然后让每个人跑好几遍。

**为什么：** 文档里的例子说明不了你的产品。安装必须结束在你自己的材料上，否则你始终不知道这个东西对你有没有用。

**磁盘上会改变什么：** `runs/` 下多出一份运行报告。装了 Docker 的话，它会构建环境镜像：第一次要几分钟，看起来像卡住了，我会在开始前提醒你。

**你会得到：** 一份报告，每次运行都保留自己的记录，包括没通过检查的回答。

**岔路：** 有 Docker 还是没有。没有它，四个环境起不来，但人物生成和报告照常工作。现在装 Docker，还是先看已经能跑的部分？
➡️ 如果这是你第一次来，我建议 Docker 留到以后。

## 第 6 步：给你看结果，也给你看数据边界

**我在做什么：** 把报告变成一个 HTML 页面，打开它，和你一起读：总体数字、按群体的拆分、聚合方法。然后跑一次许可闸门。

**为什么：** 一个总体数字几乎说明不了什么，有意思的是群体之间的差别。而闸门会显示人们通常想起来太晚的事：哪些数据你可以转交出去，哪些不行。

**磁盘上会改变什么：** 报告旁边多出一个 HTML 文件。闸门只读，不写。

**你会得到：** 浏览器里的一个页面，以及一行 `лицензионная граница: цела`，意思是许可边界完好。到这里，你知道 Mantoz 能做什么，也知道它的边界在哪里。

```bash
uv run python -m mantoz.viewer render --report runs/first.json --out runs/first.html
sh evals/licence_boundary_gate.sh
```
