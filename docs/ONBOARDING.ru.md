# Онбординг: первый прогон Mantoz

<p align="center"><img src="assets/pantheon/doc-onboarding.png" alt="Мраморная чаша на низкой ступени при дневном свете, перед ней одна небольшая мраморная фигура и синяя нить по полу, справа семейная колонна" width="100%"></p>

Написано для тех, кто делает это впервые. На каждом шаге сказано, что набрать и что появится на
экране. Минут пятнадцать целиком, большая часть уходит на скачивание.

В конце у вас будет отчет по толпе из нескольких сотен сгенерированных людей, которые заполнили
одну и ту же анкету, и HTML-страница, где видно, как ответила каждая группа.

---

## Шаг 1. Откройте терминал

На macOS нажмите `Cmd + Space`, наберите `Terminal`, нажмите Enter. На Linux откройте свое
терминальное приложение.

**На экране:** окно со строкой приглашения, которая кончается на `$` или `%`. Туда идут команды.

## Шаг 2. Проверьте, есть ли Python

```bash
python3 --version
```

**На экране:** что-то вроде `Python 3.12.4`. Если версия ниже 3.12, все равно идите дальше: шаг 4
поставит нужную, системный Python при этом не тронется. Если команда вообще не находится, сперва
поставьте Python с [python.org](https://www.python.org/downloads/).

## Шаг 3. Заберите код

```bash
git clone https://github.com/zarubinvibe/mantoz.git ~/mantoz
cd ~/mantoz
```

**На экране:** несколько строк со счетом объектов и `Resolving deltas: 100%`. После `cd` в
приглашении обычно появляется `mantoz`.

Git на машине нет? Скачайте
[ZIP](https://github.com/zarubinvibe/mantoz/archive/refs/heads/main.zip), распакуйте и зайдите
`cd` в распакованную папку.

## Шаг 4. Поставьте uv

`uv` собирает окружение и тянет Harbor.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**На экране:** строка прогресса, потом `installed uv`. Закройте терминал и откройте заново или
выполните `source ~/.bashrc`, чтобы оболочка увидела новую команду. Проверьте через `uv --version`.

## Шаг 5. Запустите установщик

```bash
bash install.sh
```

**На экране:** найденная версия Python, затем `dependencies installed, Harbor included`, затем
список проверок, каждая начинается с `ok`, и в конце `all 21 checks passed`.

Строка, начинающаяся с `!!`, читается целиком: установщик прямо называет, чего не хватает и какой
командой это добрать. Отсутствие Docker на этом шаге пока не мешает.

## Шаг 6. Сгенерируйте толпу и посмотрите на нее

```bash
uv run python -m mantoz.persona sample --n 200 --seed 7 --dag --out runs/people.json
```

**На экране:** ничего, и это значит, что все получилось. В файле `runs/people.json` теперь двести
сгенерированных людей. Откройте его или пересчитайте:

```bash
python3 -c "import json;print(len(json.load(open('runs/people.json'))))"
```

**На экране:** `200`.

Часть `--seed 7` тут важна: повторите ту же команду и получите ровно тех же двести человек.
Поменяйте seed, и толпа будет другая.

## Шаг 7. Прогоните толпу через анкету

```bash
uv run python -m mantoz.population run --n-runs 3 --seed 7 --task survey --out runs/first.json
```

**На экране:** строки прогресса, пока идут прогоны, потом команда завершается. `--n-runs 3` значит,
что каждая персона отвечает трижды: один ответ ничего не доказывает про человека и тем более про
популяцию.

**Если оборвалось на ошибке Docker:** среде анкеты нужен Docker. Поставьте
[Docker Desktop](https://www.docker.com/products/docker-desktop/), запустите его и повторите
команду.

## Шаг 8. Превратите отчет в страницу

```bash
uv run python -m mantoz.viewer render --report runs/first.json --out runs/first.html
open runs/first.html
```

На Linux вместо `open` используйте `xdg-open runs/first.html`.

**На экране:** страница в браузере со сводным результатом, разбивкой по подгруппам и явно
записанным методом агрегации.

## Шаг 9. Проверьте лицензионную границу до любого коммита

```bash
sh evals/licence_boundary_gate.sh
```

**На экране:** `лицензионная граница: цела`. Эти ворота не пускают в git опросные данные,
производные маргиналы и веса моделей. Прогоняйте их перед каждым push, особенно если добавили свой
источник данных.

## Шаг 10. Попробуйте другую среду

Анкета тут одна из четырех. Смените задачу, и та же толпа пойдет через чат поддержки, веб-страницу
или десктопное приложение:

```bash
uv run python -m mantoz.population run --n-runs 3 --seed 7 --task chat --out runs/chat.json
```

**На экране:** вывод той же формы, но из другой среды.

## Как обновляться

Новая версия выходит время от времени. В Claude Code запустите `/mantoz-update`: он покажет, что
изменилось, до того как что-то тронет, подтянет только вперед, не тронет ваш `data/`, прогоны и
`.env`, а после обновления заново прогонит обе проверки. Без агента то же самое руками:

```bash
cd ~/mantoz
git pull --ff-only origin main
uv pip install -e .
bash scripts/mantoz-selfcheck.sh --selftest
```

**На экране:** список приехавших коммитов, потом снова зеленые проверки.

Поставьте проекту звезду: [https://github.com/zarubinvibe/mantoz](https://github.com/zarubinvibe/mantoz).

Нашли ошибку? Заведите issue на
[https://github.com/zarubinvibe/mantoz/issues](https://github.com/zarubinvibe/mantoz/issues) и
напишите, что запускали и что получилось.
