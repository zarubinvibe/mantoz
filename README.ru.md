## Что это

Mantoz собирает толпу выдуманных людей, прогоняет через одну задачу каждого и показывает, как ответила каждая группа. Люди сгенерированы: возраст, доход, город, привычки, что для них важно. Задача при этом настоящая. Анкета, чат поддержки, веб-страница, десктопное приложение. С машины наружу ничего не уходит, пока вы сами не включите платную модель.

## Зачем это нужно

Форму можно выкатить и через месяц узнать, что люди старше пятидесяти ее не дочитывали. Спросить живых пользователей стоит недель и денег, которых на этой стадии обычно нет. Выдуманная толпа их не заменит. Зато она рано ловит громкие поломки: вопрос, который никто не понял, кнопку, до которой одна группа не дошла, формулировку, понятную вам и больше никому.

## Главное преимущество

**Главное преимущество:** вердикт выносит проверка, встроенная в саму задачу, и выносит его помногу раз, а не однажды.

**Почему это лучше:** Один прогон одного агента ничего не говорит о популяции. Mantoz гоняет каждую персону через задачу по нескольку раз, у каждой задачи своя проверка, а свободные ответы уходят двум судьям: расхождение между ними замеряется и лежит рядом с сырым текстом. Вы читаете разброс, а не единственный удачный ответ.

## Как это работает

Пять шагов. После каждого на диске остается файл, поэтому прерванный прогон продолжается с записанного.

| Этап | Что происходит |
|---|---|
| 1. Толпа | Толпа персон генерируется по схеме |
| 2. Статистика | Реальная статистика подтягивает толпу к реальности |
| 3. Прогон | Все проходят одну и ту же задачу |
| 4. Проверка | Задача сама решает, засчитан ответ или нет |
| 5. Отчет | Прогоны сводятся и разбиваются по подгруппам |

### Шаг 1: Соберите толпу

Вы говорите, сколько людей нужно и с каким seed. Mantoz собирает их по схеме из сорока измерений в четырех группах: происхождение, психология, способности, поведение. Граф зависимостей держит их связными, чтобы у девятнадцатилетнего не оказалось тридцати лет управленческого стажа.

**Что получится:** воспроизводимая толпа на диске: один и тот же seed всегда дает одних и тех же людей.

### Шаг 2: Притяните к реальной статистике

Толпа, взятая из воздуха, слишком гладкая: живые популяции так не выглядят. Импортируйте маргиналы из открытого статистического источника, и сэмплер пойдет по этим долям вместо своих умолчаний. В комплекте едут только источники, где коммерческое использование разрешено.

**Что получится:** толпа, доли в которой сходятся с опубликованной статистикой, а рядом записаны источник и его лицензия.

### Шаг 3: Прогоните всех через задачу

Задача живет в одной из четырех сред: анкета, чат поддержки, веб-страница, десктопное приложение. Каждая персона проходит ее по нескольку раз, потому что один прогон одного агента годится только на байку. Исполнение идет через Harbor, а бэкенд песочницы переключается конфигом: Docker по умолчанию, Modal если платите.

**Что получится:** по одному трейсу на прогон, целиком, включая ответы, которые не прошли.

### Шаг 4: Пусть задача судит сама

У каждой задачи свой верификатор, поэтому ничего не оценивает универсальный ревьюер, который рубрику в глаза не видел. Свободные ответы уходят двум судьям. Расхождение между ними замеряется, а сырой текст обоих ложится в вердикт, чтобы странную оценку можно было прочитать, а не угадывать.

**Что получится:** вердикт на каждый прогон, где сырой ответ судьи сохранен, а не свернут в сводку.

### Шаг 5: Читайте по подгруппам

Отдельные прогоны считаются до уровня всей популяции и каждой подгруппы, а метод агрегации записан в отчет, а не подразумевается. Тонкий вьювер превращает отчет в одну HTML-страницу. Второго фронтенда нет, сборки нет, сервера нет.

**Что получится:** одна страница, где видно, как ответила каждая группа и где группы разошлись.

## Быстрый старт

Нужны macOS или Linux, Python 3.12 и `uv`. Еще Docker, если хотите песочницы сред. Ниже три двери, годится любая.

```bash
git clone https://github.com/zarubinvibe/mantoz.git ~/mantoz
cd ~/mantoz
python3 --version          # 3.12 or newer; the installer says so if yours is older
bash install.sh

claude                     # in Claude Code, then type /mantoz-setup
code .                     # or just open the project in your editor

uv run python -m mantoz.population run --n-runs 3 --seed 7 --task survey --out runs/first.json
uv run python -m mantoz.viewer render --report runs/first.json --out runs/first.html
```

Нет Git? Скачайте [ZIP](https://github.com/zarubinvibe/mantoz/archive/refs/heads/main.zip), распакуйте и запустите внутри тот же `bash install.sh`. Хотите пакет без клона? `uv pip install git+https://github.com/zarubinvibe/mantoz.git` ставит его прямо из репозитория. Впервые здесь? Откройте проект в Claude Code и запустите `/mantoz-setup`: установка идет разговором, по одному вопросу, и ничего не ставится без вашего «да». Уже стоит? `/mantoz-update` подтянет текущую версию и покажет изменения до того, как что-то тронет.

Делаете это впервые? [Онбординг](docs/ONBOARDING.ru.md) проводит весь первый запуск по шагам и говорит, что видно после каждой команды.

**Что получится:** отчет по популяции на диске и одна HTML-страница, которую открываешь в браузере: разбивка по подгруппам уже посчитана.

## Безопасность и приватность

- Все крутится на вашей машине. Сервера Mantoz нет, аккаунт заводить негде.
- `data/` в git не попадает. Лицензионные ворота отклоняют коммит, который тащит опросные данные, производные маргиналы или веса модели.
- В граунде один источник: Росстат через tochno.st, CC BY 4.0, коммерческое использование разрешено письменно.
- Источник с запретом на передачу помечен `local_only`, и производное от него машину не покидает.
- LLM-судьи выключены. Пока вы сами не передадите `--live-provider`, работает бесплатный детерминированный судья.
- Среды задач крутятся в Docker. Бэкенд Modal подключается отдельно и стоит денег.

Перед любым push прочитайте `git diff` и прогоните `sh evals/licence_boundary_gate.sh`.

## Ограничения

Статус: MVP закрыт. Семнадцать тикетов, все четыре среды работают, чек-лист паритета зеленый.

- Сгенерированные люди не живые пользователи. Результат стоит считать гипотезой к проверке, а не доказательством.
- Граунд пока держится на российской статистике. Другой стране нужен источник с таким же письменным разрешением.
- Четыре среды нарочно простые: форма, чат, страница, окно приложения. Вашим продуктом они не станут.
- Вывод команд и тексты ошибок на русском. Документация нет.

Глубже: [чек-лист паритета](docs/PARITY.md) сравнивает Mantoz построчно с опубликованной исследовательской сборкой, а [словарь](docs/CONTEXT.md) объясняет слова, которыми проект пользуется. Метод персон взят как исследование и процитирован: [arXiv:2608.04205](https://arxiv.org/abs/2608.04205). Исполнение агентов идет через [Harbor](https://github.com/harbor-framework/harbor), Apache-2.0, зависимостью, смотрите [NOTICE](NOTICE).
