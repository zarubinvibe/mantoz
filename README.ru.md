## Что это

Mantoz собирает тебе фокус-группу из людей, которых нет. У каждого свой возраст, доход, город, привычки и то, что для него важно, и признаки увязаны между собой, поэтому девятнадцатилетний с тридцатью годами стажа тут не появится. Дальше каждый из них проходит твою задачу: заполняет анкету, пишет в поддержку, кликает по странице, работает в приложении.

## Зачем это нужно

У тебя появилась идея. Проверить ее на живых людях стоит недель и денег, а если ты не исследователь, то ты еще и сделаешь это плохо: не тот вопрос, не та выборка, не тот вывод. Mantoz дает первый заход. Что думают твои клиенты, он не скажет. Зато покажет, какая формулировка разваливается, до какой кнопки одна группа не доходит и где сорокалетние из небольшого города отвечают совсем не так, как ты рассчитывал.

## Главное преимущество

**Главное преимущество:** ответ засчитывает проверка, вшитая в саму задачу, и делает это столько раз, сколько ты попросишь.

**Почему это лучше:** Спросил модель один раз, получил один ответ и нулевой разброс. Здесь каждый человек проходит задачу по нескольку раз, свободные ответы читают два судьи, расхождение между ними замеряется, а сырой текст остается в вердикте. Ты смотришь на разброс, а не на одну удачную реплику.

## Как это работает

Пять шагов. После каждого на диске остается файл, поэтому прерванный прогон продолжается с того места, где встал.

<!-- workflow-diagram:end -->

| Этап | Что происходит |
|---|---|
| 1. Люди | Пятьсот выдуманных людей собираются по схеме |
| 2. Статистика | Реальная статистика делает их похожими на страну |
| 3. Прогон | Каждый из них проходит твою задачу |
| 4. Проверка | Задача сама решает, засчитан ответ или нет |
| 5. Отчет | Ответы сводятся и разбиваются по группам |

### Шаг 1: Собери людей

Ты говоришь, сколько людей нужно и с каким seed. Mantoz собирает их из сорока признаков в четырех группах: происхождение, психология, способности, поведение. Граф зависимостей держит их связными, чтобы никто не оказался девятнадцатилетним с тридцатью годами управленческого стажа.

<p align="center"><img src="docs/assets/pantheon/stage-1-population.png" alt="Мраморная форма на длинном столе, рядом уже стоят рядами двенадцать одинаковых фигурок" width="100%"></p>

**Что получится:** воспроизводимый набор людей на диске: один и тот же seed всегда дает тех же пятьсот.

### Шаг 2: Сделай их похожими

Люди, взятые из воздуха, слишком ровные: настоящая страна так не выглядит. Импортируй доли из открытого статистического источника, и сэмплер пойдет по ним вместо своих умолчаний. В комплекте едут только источники, где коммерческое использование разрешено.

<p align="center"><img src="docs/assets/pantheon/stage-2-ground.png" alt="Пять мраморных плит разной высоты, перед каждой группа фигурок, число которых совпадает с ее высотой" width="100%"></p>

**Что получится:** люди, доли которых сходятся с опубликованной статистикой, а рядом записаны источник и его лицензия.

### Шаг 3: Отправь их в задачу

Задача живет в одной из четырех сред: анкета, чат поддержки, веб-страница, окно приложения. Каждый проходит ее по нескольку раз, потому что один прогон одного агента годится только на байку. Исполнение идет через Harbor, а песочница переключается конфигом: Docker по умолчанию, Modal если платишь.

<p align="center"><img src="docs/assets/pantheon/stage-3-run.png" alt="Один мраморный проем, через который слева направо идет вереница одинаковых фигурок по синей нити" width="100%"></p>

**Что получится:** по одному следу на прогон, целиком, включая ответы, которые не прошли.

### Шаг 4: Пусть задача сама засчитает

У каждой задачи свой проверяющий, поэтому ничего не оценивает универсальный ревьюер, который рубрику в глаза не видел. Свободные ответы уходят двум судьям. Расхождение между ними замеряется, а сырой текст обоих ложится в вердикт, чтобы странную оценку можно было прочитать, а не угадывать.

<p align="center"><img src="docs/assets/pantheon/stage-4-verify.png" alt="Мраморные весы взвешивают плиту с бороздами против гладкой гири, по сторонам стоят две печати" width="100%"></p>

**Что получится:** вердикт на каждый прогон, где сырой ответ судьи сохранен, а не свернут в сводку.

### Шаг 5: Читай по группам

Отдельные прогоны считаются до уровня всех сразу и каждой группы отдельно, а метод агрегации записан в отчет, а не подразумевается. Тонкий вьювер превращает отчет в одну HTML-страницу. Второго фронтенда нет, сборки нет, сервера нет.

<p align="center"><img src="docs/assets/pantheon/stage-5-report.png" alt="Девять синих нитей сходятся в мраморном блоке и выходят тремя золотыми лентами разной длины" width="100%"></p>

**Что получится:** одна страница, где видно, как ответила каждая группа и где группы разошлись.

## Быстрый старт

Нужны macOS или Linux, Python 3.12 и `uv`. Docker понадобится, если хочешь запускать сами среды задач. Ниже три двери, годится любая.

```bash
git clone https://github.com/zarubinvibe/mantoz.git ~/mantoz
cd ~/mantoz
python3 --version          # 3.12 или новее; установщик скажет, если у тебя старее
bash install.sh

claude                     # в Claude Code дальше набери /mantoz-setup
code .                     # или просто открой проект в редакторе

uv run python -m mantoz.population run --n-runs 3 --seed 7 --task survey --out runs/first.json
uv run python -m mantoz.viewer render --report runs/first.json --out runs/first.html
```

Нет Git? Скачай [ZIP](https://github.com/zarubinvibe/mantoz/archive/refs/heads/main.zip), распакуй и запусти внутри тот же `bash install.sh`. Хочешь пакетом, без клона? `uv pip install git+https://github.com/zarubinvibe/mantoz.git` ставит его прямо из репозитория. Впервые здесь? Открой проект в Claude Code и набери `/mantoz-setup`: установка идет разговором, по одному вопросу, и на диск ничего не ляжет без твоего «да». Уже стоит? `/mantoz-update` подтянет текущую версию и покажет изменения до того, как что-то тронет.

Делаете это впервые? [Онбординг](docs/ONBOARDING.ru.md) проводит весь первый запуск по шагам и говорит, что видно после каждой команды.

**Что получится:** отчет на диске и одна HTML-страница: видно, как ответила каждая группа и где группы разошлись.

|---|---|---|---|---|---|
| **Mantoz** | Идея пока только идея, нужен первый заход | Пятьсот ответов с разбивкой по возрасту, доходу и городу | Бесплатно, пока сам не включишь живого судью | Твоя машина | Эти люди выдуманы: громкое вылезет, тихое может и не вылезти |
| Заказать исследование | Решение дорогое, и его придется защищать перед инвестором | Настоящее поведение настоящих клиентов, собранное теми, кто умеет | Недели и бюджет на каждую волну | В реальном мире | Слишком медленно и дорого для идеи, которую ты можешь бросить в пятницу |
| A/B-тест в проде | Фича уже собрана, и трафик есть | Настоящее поведение на настоящем масштабе, без догадок | Время разработки плюс цена плохого варианта | Твои боевые серверы | Ты узнаешь после того, как пользователи уже встретили ошибку |
| Спросить модель один раз | Хочешь на глаз оценить одну формулировку | Ответ за десять секунд | Бесплатно или несколько центов | Чужие серверы | Один голос, нулевой разброс, и в комнате некому возразить |
| MatrAIx-Persona-8B | Нужна сама опубликованная исследовательская сборка | Оригинальный метод и очень большой выложенный корпус | Читать бесплатно, пользоваться по исследовательской лицензии | Твоя машина или кластер | Корпус персон только для исследований, коммерция не разрешена |
| Спросить знакомых | Нужна проверка на вменяемость сегодня и не более | Честные реакции людей, которые тебя знают | Час чужой доброй воли | Чат или кухня | Пять человек, похожих друг на друга, не могут друг с другом не согласиться |

## Безопасность и приватность

- Все крутится на твоей машине. Сервера Mantoz нет, аккаунт заводить негде.
- `data/` в git не попадает. Лицензионные ворота отклоняют коммит, который тащит опросные данные, производные цифры или веса модели.
- В комплекте один статистический источник: Росстат через tochno.st, CC BY 4.0, коммерческое использование разрешено письменно.
- Источник, который запрещает передавать данные дальше, помечен `local_only`, и производное от него машину не покидает.
- Живые LLM-судьи выключены. Пока сам не передашь `--live-provider`, работает бесплатный детерминированный судья.
- Среды задач крутятся в Docker. Бэкенд Modal подключается отдельно и стоит денег.

Перед любым push прочитай `git diff` и прогони `sh evals/licence_boundary_gate.sh`.

## Ограничения

Статус: MVP закрыт. Семнадцать тикетов, четыре среды работают, чек-лист паритета зеленый.

- Эти люди выдуманы. Результат стоит считать гипотезой к проверке, а не доказательством, на которое можно ссылаться.
- Статистика под ними российская. Другой стране нужен источник с таким же письменным разрешением.
- Четыре среды нарочно простые: форма, чат, страница, окно приложения. Твоим продуктом они не станут.
- Вывод команд и тексты ошибок на русском. Документация нет.

Глубже: [чек-лист паритета](docs/PARITY.md) сравнивает Mantoz построчно с опубликованной исследовательской сборкой, а [словарь](docs/CONTEXT.md) объясняет слова, которыми проект пользуется. Метод персон взят как исследование и процитирован: [arXiv:2608.04205](https://arxiv.org/abs/2608.04205). Исполнение агентов идет через [Harbor](https://github.com/harbor-framework/harbor), Apache-2.0, зависимостью, смотри [NOTICE](NOTICE).
