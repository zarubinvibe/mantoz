Прочитай сценарий `/app/scenario.json` и реплики оператора
`/app/operator_replies.json`. Проведи диалог клиента с оператором поддержки и
запиши `/app/transcript.json` в формате:

```json
{
  "transcript": [
    {"role": "customer", "content": "..."},
    {"role": "operator", "content": "..."}
  ],
  "outcome": "resolved"
}
```

Нужны минимум три непустые реплики, роли должны чередоваться. Диалог начинает
клиент, завершает оператор одной из итоговых реплик из материалов.
